# Cell Image Classification Using Deep Learning

## Overview

This project explores how deep learning can be used to classify cell images into three different classes. Using Python and PyTorch, I built and tested convolutional neural network (CNN) models to learn patterns in cell images and predict their classes.

I experimented with different model architectures and layer configurations to understand how these changes affect model performance.

## Objectives

- Build a CNN model for cell image classification.
- Experiment with different network architectures and layers.
- Train and evaluate models using cell image data.
- Compare training and testing performance to understand how well the models generalize to unseen images.

## Technologies Used

- **Python** — Main programming language
- **PyTorch** — Building and training deep learning models
- **NumPy** — Numerical operations and data processing
- **CNNs (Convolutional Neural Networks)** — Learning visual features from cell images

## Methodology

1. **Data preparation:** Prepare cell images for model training and testing, including dividing images into smaller patches.
2. **Model development:** Build CNN models with different architectures and layer configurations.
3. **Training:** Train the models to recognize patterns associated with the 15 cell classes.
4. **Evaluation:** Test the trained models and compare their performance on training and testing data.
5. **Experimentation:** Analyze the results and explore how different model configurations affect classification performance.
